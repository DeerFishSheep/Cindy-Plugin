打开 a6api.com ↗

自动同步怎么工作：随包 Node 进程读取本机 Chrome / Edge / Brave 的 Cookies 数据库，用 macOS 钥匙串里的 Chrome Safe Storage 解密 a6api 的 Cookie，再从浏览器 Local Storage 读用户 ID。第一次读取时 macOS 可能询问是否允许访问钥匙串，拒绝或读不到就用上面的手动粘贴。

降级说明：如果 Chrome 正在运行且数据库被锁，复制用的是临时快照，通常仍可读；如果浏览器用了新的加密方式、或你只登录在 Cindy 内嵌浏览器里，自动同步会失败——手动粘贴 Cookie 和账号密码登录始终可用。

数据存放：Cookie 在 Cindy 保险库；用户 ID、令牌选择和筛选条件在插件 /kv；榜单快照与收藏在插件私有数据目录。插件不写 ~/.dsh、~/.pi-desktop。
